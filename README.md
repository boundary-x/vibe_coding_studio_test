# 바이브코딩 스튜디오 · 모델 비교 테스트

테스트 주소: https://boundary-x.github.io/vibe_coding_studio_test/

운영 저장소와 별개의 테스트 사이트입니다. 원본: https://github.com/boundary-x/vibe_coding_studio (index.html blob 92fbab429e3cdd8e83c41b157f9842f6104f3230).

## 사용
1. 상단 API 키 입력에서 Gemini와 Claude의 실제 API 키를 입력합니다. 기존 수업용 접속키가 아닙니다.
2. 제품과 모드를 선택하고 요청하면 같은 질문·기존 코드·시스템 규칙을 두 업체에 각각 1회 전송합니다.
3. 나란히 표시된 응답·시간·토큰·추정 비용을 비교합니다.
4. https://boundaryx.io/edu_2 에서 제품별 MakeCode 환경을 열어 블록 변환과 로봇 동작을 확인하고 결과별 평가를 남깁니다.
5. 한 결과를 에디터에 반영하거나, 적용하지 않고 닫습니다. 비교 기록에서 평가를 수정하고 JSON으로 내려받을 수 있습니다.

키는 브라우저 메모리에서만 사용하며 localStorage, 쿠키, GitHub 저장소에 저장하지 않습니다. 새로고침하면 지워집니다. 요청은 Google/Anthropic API로 직접 전송됩니다. 이 방식은 개인 테스트용이며 운영 서비스의 서버 프록시를 대체하지 않습니다.

## 조건
- Gemini 3.8 Flash / Claude Haiku 5.5. 계정에서 모델 접근이 가능해야 합니다.
- 출력 한도 8192, 제한 120초, 자동 재시도 없음, 업체별 기본 추론·temperature.
- 원본 웹앱의 포니봇·바이브램프 프롬프트를 유지합니다. 최신 확장 버전과 동일하지 않습니다.
- API 반환 토큰에 캐시 할인 전 단가를 곱한 추정 비용입니다. 세금·무료 할당량·실패 호출 과금은 반영하지 않습니다.
- Gemini 단가 입력 .75 / 출력 3.75 USD/1M (2026년 말까지; 이후 1.5/7.5). Haiku 입력 100K 이하 .10/.50, 초과 .50/2.50. 요금표 기준일 2026-11-19.
- 블록 변환·실제 동작은 자동 검사하지 않습니다. 원본 파서의 ⚠️ 응답 거부 조건도 유지하므로 코드 주석이 거부되는 사례는 별도로 기록하세요.
- 최근 40건은 탭 메모리에만 보관합니다. JSON에는 질문·코드·규칙·결과가 포함되며 키는 제외됩니다.
- 두 키를 입력하고 요청할 때 API 요금이 발생할 수 있습니다. 실제 API 키를 이용한 호출 검증은 사용자가 수행합니다.
